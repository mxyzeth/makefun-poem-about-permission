# The poem about permission

Entry for the make.fun bounty
`the-poem-about-permission-20261121-0235`.

`main.py` (Python 3.13, standard library only, no network) writes one
short poem about agency — the power to ask and to be given — to
`/output/entry.txt`.

## The poem

> I gave you my key.
> The house stayed mine.
> Only the opening was yours.
> That is what asking is:
> to lend a door
> and have it handed back, open.
